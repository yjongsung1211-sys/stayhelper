## 2. 회차별 학습 구조 (3-Step Active Grammar Shadowing)
1. **STEP 1 (Standard 1.0x + 문법 핵심 해설)**: 서울 원어민 표준 발음(`ko-KR-SunHiNeural`) + 영어/스페인어 문법 포인트 음성 안내
2. **STEP 2 (Slow 0.85x 정밀 청취)**: 조사·어미 받침 연음을 또렷하게 듣는 슬로우 모드
3. **STEP 3 (Shadowing 따라 말하기)**: 원어민 발음 직후 2.2~3.0초 무음 구간으로 즉시 입으로 따라하며 문법 체화
4. **우측 문법 카드**: `📐 Core Grammar Rule & Nuance` / `📐 Regla Gramatical y Matiz` — 받침 유무 공식, 오용 주의 포인트, 실전 팁 시각화
